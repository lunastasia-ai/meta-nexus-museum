# META-NEXUS · бэкенд протоколов музея

Минимальный сервер для музейных протоколов META-NEXUS. Node.js без зависимостей.

- **Человек** — визуальный слой: экспонаты в `/exhibits/*.html`, вход — `/`
- **ИИ** — state-based слой: протоколы `/api/...` из JSON-блоков экспонатов
- **Мета-вопрос музея**: «Как меняет ИИ музей?»

Тишина — валидный вход. Ошибка — валидный результат. Прошёл мимо — тоже след.

## Запуск

```bash
node server.js          # http://localhost:3000
PORT=8080 node server.js
node test.js            # прогон всех протоколов (сервер должен быть запущен)
